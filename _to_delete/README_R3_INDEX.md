# Sofpad — source index

Sofpad is a wireless, unibody Sofle RGB keyboard with a trackpad. It targets HTPC and couch control.

| Folder | Status | Note |
|---|---|---|
| `sofle_single_controller/` | **Current (R3)** | One nRF52840, one battery, Cirque 40 mm SPI trackpad. Work here. |
| `sofle_unibody_v2/` | Superseded | Uses the Azoteq TPS43-201 trackpad. This part is end-of-life. |
| `sofle_couch/` | Superseded | First case concept. It also uses the TPS43-201. |

Do not edit the superseded folders. Keep them for reference only.
